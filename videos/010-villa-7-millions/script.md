# Script voix off — Vidéo 010 (≈ 195 mots, 64,7 s) — v5

Structure des exemples : intro rapide des points forts (sans le prix) → « Voici ce que tu peux avoir pour seulement
7 millions d'euros » → « On commence par… » → visite dans l'ordre, une phrase courte par pièce → piscine → 1 ou 2.
Voix : Chloé (ElevenLabs). Ton de conteuse complice, très dynamique sur l'intro.
Règle : si deux éléments s'enchaînent trop vite, on n'en garde qu'un (une flèche, une mention).
