# Script voix off — Vidéo 010 (≈ 205 mots, 64 s) — v4 « comme les exemples »

Structure des exemples : accroche → intro rapide des points forts → « On commence par… » → visite dans l'ordre,
une phrase courte par pièce, déco marquante comprise (porte, cheminée, lustres…) → piscine → « Alors, sois honnête : 1 ou 2 ».
Voix : Chloé (ElevenLabs). Ton de conteuse complice, plus intense sur les 3 premières secondes.
