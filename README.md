# Vid-o-

Projet vidéo basé sur [Remotion](https://www.remotion.dev/).

## Commandes

```bash
npm install      # installer les dépendances
npm run dev      # ouvrir Remotion Studio (aperçu)
npm run render   # rendre la vidéo dans out/video.mp4
```

Les compositions sont déclarées dans `src/Root.tsx`.
